# Support

Use [GitHub Issues](https://github.com/bashar12-dev/barcode_port/issues) for
reproducible bugs, usage questions, and device compatibility reports. Search
existing issues first and include a minimal example.

For hardware issues include:

- Device/scanner model, Android version, and firmware version.
- USB/Bluetooth keyboard-wedge mode or iMin broadcast mode.
- Prefix/suffix and broadcast settings relevant to the reproduction.
- Flutter and BarcodePort versions, expected result, actual result, and errors.
- Whether editable focus, route visibility, or app background state matters.

Use synthetic values. Do not post customer barcodes, payment data, credentials,
or device serial numbers in a public issue. A model report does not qualify all
firmware revisions or all devices using the same connection technology.

Maintenance is best effort; there is no commercial support or guaranteed response
time. Report security issues privately as described in [SECURITY.md](SECURITY.md).
